# dual-sub-merge

中文 + 外文**单语字幕**一键合并为 Aegisub 可用的双语 ASS（英文 `.chs+eng.ass`，日文 `.chs+jpn.ass`，按外文语言命名）。

面向字幕整理 / 压制流程：清洗文本、统一 HDRipad / Dial 样式、可选删致谢、可选从 MKV/MP4 抽内嵌轨。

---

## 功能一览

| 能力 | 说明 |
|------|------|
| 批量输入 | **单一输入**：拖到窗口任意位置即可识别，字幕与视频可一起拖入；也可点「文件」/「文件夹」直接选，扫描后按文件名前缀自动配对，可处理的全部列出 |
| 输出目录 | 只两项：`./Subtitles/`（输入目录下的子目录，默认）或 `./`（源文件夹旁） |
| 路径拖放 | 整个窗口任意位置都是落点，拖入时整窗高亮反馈 |
| 勾选处理 | 扫描后**默认全选**，可取消勾选跳过部分条目；支持清空列表 |
| 工作区 | 左侧栏在**字幕处理**与**视频抽轨**之间切换；字幕处理页顶部标签页切换中英配对 / 中日配对 / 样式转换 / 中文转换，即时生效并持久化 |
| 处理方式 | 字幕处理页顶部标签页切换：中英配对 / 中日配对 / 样式转换 / 中文转换；切换后列表与主按钮一起变 |
| 手动标记 | 列表行内可改**语言角色**（中/外/未知）；同路径重扫尽量保留，清空列表时丢弃 |
| 标记语言改名 | 可选：无尾部语言标记的源字幕**移动**到 `chs-sub/`、`eng-sub/`，文件名加 `.chs`/`.eng`（日文内容识别为假名时加 `.jpn`）；可「仅改名」或「改名并中英配对」 |
| 格式 | 输入 `ass` / `ssa` / `srt` / `vtt`（UTF-8、UTF-16LE/BE）；输出 ASS |
| 清洗 | `\N`/换行→空格；去特效与位置标签；**保留斜体** |
| HTML 斜体 | SRT 的 `<i>` / `<em>` → `{\i1}` / `{\i0}` |
| 标点 | 全角→半角；引号规范化；`中文,中文` → `中文, 中文` |
| 样式 | 常规模式：`中下HDRipad` / `英上HDRipad` / `annotationHDRipad` / `LyricHDRipad`；中日配对：`Dial-CH`（中文在上）/ `Dial-JP`（日文贴底）/ `annotationHDRipad` / `LyricHDRipad` |
| HDR / SDR | 勾选 **HDR**（默认，记住上次选择）输出 HDRipad / Dial 样式，正文与次色统一为 dimmed HDR 白 `&H4DFFFFFF`；取消勾选则**自动派生** SDR 样式——名字里的 `HDR` 换成 `SDR`（Dial 名不变），正文亮度改为纯白 `&H00FFFFFF`，其余字段（描边、字号、边距、歌词色）完全照搬。样式页仍只维护一套 HDR 定义 |
| 样式来源 | 内置默认、**中日参考预设**（赛博朋克：边缘行者 JPSC 的 Dial-CH/Dial-JP，中文 48 号在上、日文 32 号贴底，720p 基准）、多行粘贴、从 ASS 勾选导入。中日配对在使用内置默认样式时自动套用 Dial 表，自定义样式不被覆盖 |
| 样式缩放 | 样式几何（字号/描边/阴影/边距）按基准分辨率随输出分辨率**等比缩放**；默认预设基准 1080p，中日参考预设基准 720p，切分辨率不再需要手改字号 |
| 删除致谢 | 开关 + 正则黑名单（默认锚定「翻译:」等致谢行） |
| `\N` 样式转换 | 上下双语成品拆成双轨，统一为当前字幕样式写出 `.chs+eng.ass` / `.chs+jpn.ass`（按外文内容识别语言，保留源文件） |
| 中文转换 | 识别单中字幕（`\N` 双语会拆出中文半边），统一为当前中文字幕样式写出 `.chs.ass`；外文内容丢弃 |
| 拖拽 | 拖到**窗口任意位置**：文件夹、字幕、视频混合拖入都识别，自动判断该扫目录还是只扫选中文件 |
| 视频抽轨 | **独立工作区**：选择中英或中日后逐个视频串行抽取，进度条显示当前视频实时进度；视频卡**展开才探测**字幕轨，PGS/VobSub 等图像字幕仅展示、不勾选 |
| 性能 | 字幕解析按文件缓存，同一次扫描不重复解析；视频轨道按需探测并复用结果；合并/转换/改名后局部刷新列表，不整目录重扫 |
| 分辨率 | 默认 1080p，可选 720p / 1440p / 4K |

### 界面与交互

- 两个工作区共用同一套页面骨架：输入卡片 → 操作栏 → 任务列表 → 运行详情自上而下。
- 侧栏导航为 macOS 风格浅色选中/悬停填充（无 Material 涟漪），避免 Windows 上透明 Ink 整行变黑；顶部为字幕处理 / 视频抽轨，底部为配置项。
- 输入卡片是唯一输入入口，拖放由整窗 `DropTarget` 承担，字幕与视频共用一个输入；扫描后按内容自动切到对应工作区。
- 输出分辨率用精简下拉（触发器显示 1080p 等档位，菜单可带像素），高度与筛选芯片一致，收起悬停微蓝，切换即保存。
- 字幕处理的处理方式用顶部标签页切换，主按钮文案随之变化（开始中英配对 / 开始中日配对 / 开始转换 / 开始中文化）。
- 视频抽轨用紧凑分段控件选择中英 / 中日，主按钮固定为「开始抽轨」。
- 删除致谢、标记语言改名、HDR 三个开关用方形勾选框，选中即持久化；视频抽轨工作区隐藏这些字幕专用选项。
- 任务列表使用类型与状态徽标；缺轨/冲突等标黄色「需检查」，可点徽标仅显示需检查项；中文文件始终在外文上方。
- 视频任务卡默认折叠，显示「未探测」与「展开并读取字幕轨」；展开后才读取并列出容器中的全部字幕轨、语言、标题、编码与默认/强制/SDH 标记，可逐轨勾选需要抽取的字幕。
- 运行详情默认收起，扫描、合并和抽轨进度在主操作区即时反馈；需要时可展开查看完整日志。
- 1280×720 为推荐窗口尺寸，较窄桌面窗口会自动收紧侧栏与间距。

### 样式优先级

常规配对 / 样式转换：

1. `LyricHDRipad` — 首尾 `*` 或含 ♪♫ 等  
2. `annotationHDRipad` — 源含 `\an8`  
3. 中文轨 → `中下HDRipad`（SDR 模式下为 `中下SDRipad`）  
4. 外文轨 → `英上HDRipad`（SDR 模式下为 `英上SDRipad`）  

中日配对（内置默认样式时自动使用 Dial 表，基准 720p）：

1. `LyricHDRipad` / `annotationHDRipad` — 歌词与顶部注释优先  
2. 中文轨 → `Dial-CH`（48 号、MarginV 40，在上）  
3. 日文轨 → `Dial-JP`（32 号、MarginV 10，贴底）  

关闭 HDR 时，Dial 名保持不变，HDRipad 名改为 SDRipad，正文主色改为纯白，其余字段保持原样。

### 文件名语言标记（优先）

中文：`chs` `cht` `zh` `cn` `chi` …  
外文：`eng` `en` `sdh` `jpn` `kor` …  

无标记时回退内容多数表决（含假名的日文行识别为外文）。输出名：`{公共前缀}.chs+eng.ass`（外文为日文时为 `.chs+jpn.ass`，其余语言同理）；中日配对固定输出 `.chs+jpn.ass`。

可选 **标记语言改名**：仅处理文件名尾部尚无语言 token 的字幕；按识别结果移入：

```text
输入/chs-sub/{原名}.chs.srt
输入/eng-sub/{原名}.eng.srt
```

已有 `chs`/`eng` 等标记的文件不会改动。

## 使用流程

1. 把字幕或视频**拖到窗口任意位置**（文件夹 / 多文件 / 混着拖都行），或点「文件」/「文件夹」手动选
2. 左侧栏选择 **字幕处理** 或 **视频抽轨**；扫描后若当前工作区没有对应内容、另一侧有，会自动切换
3. 字幕处理：顶部标签页选择**处理方式**（中英配对 → `.chs+eng/jpn.ass` / 中日配对 → `.chs+jpn.ass` / 样式转换 → `.chs+eng/jpn.ass` / 中文转换 → `.chs.ass`）
4. 字幕处理：选**输出目录**：`./Subtitles/` 或 `./`
5. 查看列表（每组：**中** 在上、**外** 在下；徽标反映当前处理方式）→ 默认全选；**清空**仅清列表  
6. 按需勾选 **删除致谢** / **标记语言改名** / **HDR**  
7. 设置分辨率；字幕样式、黑名单和工具设置位于左侧栏底部
8. 点主按钮（中英配对 / 中日配对 / 转换 / 中文化；若启用标记语言则为「改名并…」）→ 生成成品  
9. 需要从容器抽轨时：左侧栏切到 **视频抽轨** → 选择 **中英** 或 **中日** → **展开**视频卡片读取字幕轨 → 勾选需要的轨道 → **开始抽轨**（逐个视频串行处理，顶部进度条显示当前视频实时进度）→ 抽出的字幕落在输入目录里，再切回 **字幕处理** 继续

字幕和视频共用一个输入，拖入的目录里有什么就扫什么。设置中可改界面字体。

抽轨文件默认写到视频所在目录下 `dual-sub-merge-extract/`（可在设置中改名）。视频卡**展开后才探测**字幕轨；展开时默认勾选中文轨（优先简中，其次未标简繁，最后繁中）加目标外文轨（中英优先英文，中日优先日文；目标语言缺失时回退到其它外文轨），仍可手动调整。中文轨使用 `chs` 标记，外文轨按容器语言标记（英文 `eng`、日文 `jpn` 等，未知时为 `eng`）；同语言多轨会附加轨道编号，避免互相覆盖。抽出的字幕会直接并入当前列表，切回 **字幕处理** 即可继续。

## 配置说明

设置与黑名单、样式通过 `shared_preferences` 持久化。

**默认致谢正则**（仅「删除致谢」开启时生效）锚定整行，例如：

```regex
^\s*翻译\s*[:：]\s*\S.*$
^\s*本字幕仅供爱好者交流[，,]\s*严禁用于任何商业途径\s*$
```

默认规则用行首锚定，避免误伤对白里的「翻译」等词。  
支持占位符 `$中文字符` → 一段汉字。

## 已知限制（v1）

- 不对中外时间轴强制对齐；双轨独立 Dialogue  
- 双语拆分目前仅支持 **`\N` / 换行上下中英**；无换行的单行中英混排不切开  
- 不 OCR 图像字幕（PGS / VobSub）  
- 容器抽轨以**桌面**为主
